02
Machine learning / Agent-based modeling

From transcriptomics to tissue-level models

My project focuses on integrating transcriptomics data into agent-based tissue-level models. I use machine learning techniques, with GeoMx transcriptomics data as input, following a multi-stage pipeline.

Supervision Dr. Dirk Drasdo and Matteo Pedrazzi

The research pipeline

GeoMx transcriptomics data is the starting input.

STEP 01cVAE
STEP 02GCN
STEP 03Boolean adjacency matrix
STEP 04MaBoSS

cVAE = conditional variational autoencoder; GCN = graph convolutional network. The pipeline connects transcriptomic input to Boolean-model simulation with MaBoSS.

03
Pure mathematics / Recursive dynamics

Piecewise sequences with dynamic thresholds

I study piecewise recursive sequences with a moving threshold. Their evolution depends on the relationship between the current term and a threshold that itself changes over time.

The mathematical object

an+1 ={
f(an) if an ≤ cn
g(an) if an > cn
cn+1 = h(an, cn)

This is my favorite mathematical object. I'm not focused on one particular conjecture or problem; I explore these sequences simply for the love of the game.
