# Slimane Alaoui Soulimani Valenti — website

A responsive two-page academic portfolio website built with HTML and CSS, ready for **GitHub Pages**.

## What's included

- `index.html` — home page, portrait, introduction, and three featured projects
- `projects.html` — full project descriptions, the cVAE → GCN → Boolean adjacency matrix → MaBoSS pipeline, a mathematical formula, and the Inria SIMBIOTX link
- `styles.css` — typography, layout, and responsive styling
- `assets/slimane-portrait.webp` — your provided portrait, optimized for the web
- `assets/favicon.svg` — browser-tab icon

## Publish it on GitHub Pages

1. Sign in to GitHub and create a **Public** repository named **`YOUR-USERNAME.github.io`**, replacing `YOUR-USERNAME` with your actual GitHub username. (If it already exists, open it.)
2. Download the ZIP of this project and unzip it on your computer.
3. Open the repository on GitHub. Select **Add file → Upload files**, or use the **+** menu if GitHub has moved that action.
4. Upload **the contents of the unzipped folder** — `index.html`, `projects.html`, `styles.css`, and the **`assets` folder**. Do not upload the containing folder by itself.
5. Select **Commit changes**.
6. Open **Settings → Pages** in your repository. Under **Build and deployment**, choose **Deploy from a branch**. Select **main** and **/(root)**, then select **Save**.
7. After a few minutes, visit **`https://YOUR-USERNAME.github.io`**.

### Important

- Keep `index.html`, `projects.html`, and `styles.css` together at the repository root. Keep the `assets` folder and its contents in the same relative location.
- The website works without a build step, package manager, external fonts, or backend.
- To edit project text in the future, open `index.html` or `projects.html` in GitHub, select the pencil/Edit button, make changes, and commit.
- The only external research link is the one supplied: <https://team.inria.fr/simbiotx/>. You can add publication/GitHub/contact links later once you have them.
